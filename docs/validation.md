# 验证范围

本机验证环境：Windows x64、DSH 0.2.0-rc.2、Codex CLI 0.163.0。其他电脑、系统或宿主版本尚未实测。

## 离线测试

在项目目录执行 `node --test tests/*.test.mjs`，共 29 项通过。覆盖额度窗口与边界、用户确认、角色/线程冲突、异步暂停、决策超时提醒、有限重试、恢复续发、完整历史与实时消息合并、面板会话隔离以及 JSON 解析失败的重生成限制。

测试使用协议替身，不调用真实模型，不执行研究实验。发行包解压后也已运行这些测试，防止依赖未打包文件。

## DSH 宿主检查

使用本机 DSH 安装包自带的 Cordis、Tools、SystemPrompt、SlotCore 运行冒烟测试，检查九个原生工具注册、结构化 schema、用户取消后的零任务、请求错误恢复 waterfall、原生消息准入与卸载清理。模型和用户回答是测试替身，不将其等同于真实模型闭环。

## 真实轻量联调

2.3.0 进行了只读、最多两轮的 Markdown 演示：第一轮 STREAM-A，暂停后由用户确认恢复，再自动实际派发第二轮 STREAM-B；任务最终 completed。

- 运行中观察到逐步增长的正文，而不是仅有 DONE 状态。
- 侧栏展示标题、加粗、列表、表格、Python/JavaScript 语法颜色与复制按钮。
- 恢复后未手动刷新或重开侧栏，新一轮状态及正文自动出现，旧轮次保留。
- 恰好两次模型轮次；没有命令、文件读写或实验操作。
- 历史读取验证了超过 6000 字的记录；界面可分页或加载全部历史，完整性以 Codex 实际保存的数据为准。

2.3.1 新增结构化计划参数与一次有条件的 JSON 错误重生成，并通过真实 DSH 宿主测试；安装页显示 v2.3.1、组件运行中。此功能不能保证模型永不产生无效 JSON，耗尽本轮恢复机会后仍会停止并报告原错误。
